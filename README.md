# GDD Space Invaders Project Starter

Space Invaders - Project 1 (Vertical Shooter)
Austin Tucker (6610660), Lizandro Campos (6632063)

We’ve put our own creative spin on the classic Space Invaders game as a two-person team with basic programming experience. With the help of a few classmates and a lot of learning along the way, we did our absolute best to ensure everything functions as intended.

Our version of the game features local two-player gameplay, spanning two distinct stages:

Scene 1: A fast-paced action stage where players battle waves of mini alien invaders for exactly 5 minutes. This stage includes power-ups such as Speed Boost and Triple Shot to enhance the experience.

Scene 2: A challenging final boss battle featuring an intense fight with a custom-designed alien boss and a new alien species.

All alien sprites and the boss were hand-drawn and compiled into animated spritesheets. The game also includes:

A Title Screen to introduce the players

A Score Dashboard that tracks and displays each player’s score throughout the game

A custom-designed Mars-themed map for the second stage to enhance visual variety and challenge

While there may be a few code inconsistencies due to our learning process, we believe the final product meets the project requirements and showcases our best effort.



### Features
- Two-player local gameplay
- Hand-drawn sprites and custom animations
- Power-ups: Speed Boost and Triple Shot
- 5-minute survival stage with enemy waves
- Final boss stage with unique enemy behavior
- Score dashboard that tracks player performance
- Custom Mars-themed map
- Scene transitions (Title Screen → Scene 1 → Scene 2)

### Controls

**Player 1:**
- Move: Arrow Keys
- Shoot: ENTER

**Player 2:**
- Move: W / A / S / D
- Shoot: SPACE
